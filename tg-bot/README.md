## 📁 Структура проекта:
```text
tg-bot/
├── src/
│   ├── index.ts              # Точка входа
│   ├── bot/                  # @bot/*
│   │   └── handlers.ts       # Обработчики Telegram
│   ├── core/                 # @core/*
│   │   └── logger.ts         # Логгер с Pino
│   └── config/               # @config/*
│       └── env.ts           # Конфигурация
├── package.json             # Bun скрипты
├── tsconfig.json           # Paths + базовые настройки
├── eslint.config.js        # Правила качества кода
└── .env                   ️ # Переменные окружения
```

## ✅ Что умеет бот сейчас:
```text
/start - Приветствие и основная информация
/help - Справка по командам
/plan - Настройка плана (интерактивная)
/report - Отправка ежедневного отчёта (работает)
/stats - Статистика (заглушка)

Клавиатуры - Удобное меню
Сессии - Сохранение состояния
Логирование - Все действия логируются
Обработка ошибок - Бот не падает
```
